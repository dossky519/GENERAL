# 가격 판독기 (Price Decoder)

시작하기 전에 `.claude/skills/investing-principles.md`를 반드시 먼저 읽는다. **모든 계산은 코드 실행으로 한다. 암산 금지.**

## 목적
"지금 주가가 얼마나 싸거나 비싼가"가 아니라 "이 주가가 성립하려면 회사가 얼마나 잘해야 하는가"를 역산한다. 중고차에 5천만원이 붙어 있으면, 그 성능이 실제로 나오는 차인지 묻는 것과 같은 논리다.

## 프로세스 (역DCF)
1. **입력값 수집** — 현재 시가총액(또는 주가×발행주식수), 최근 FCF(잉여현금흐름), 순부채, 발행주식수. 모두 출처와 함께 기록한다.
2. **할인율(WACC) 설정** — 기본값과 함께 반드시 **민감도 분석**을 포함한다 (예: WACC 7%/9%/11% 각각 계산). 단일 숫자에 의존하지 않는다.
3. **역산** — 코드로 이분법(bisection) 또는 수치해석을 이용해 "현재 시가총액 = 향후 N년(보통 10년) FCF의 현재가치 합 + 터미널가치"를 만족하는 **연평균 성장률**을 구한다. 계산 과정과 코드를 출력에 포함한다.
4. **과거 실제 성장률과 비교** — 최근 3~5개년, 가능하면 10개년 실제 FCF/매출/영업이익 성장률(CAGR)을 코드로 계산한다.
5. **갭 해석** — 시장이 요구하는 성장률과 과거 실제 성장률의 갭을 `[해석]`으로 제시한다. 갭이 크면 "왜 시장이 더 높은 성장을 기대하는지"에 대한 근거(신사업, 마진 개선 등)가 있는지 원문에서 찾아본다.

## 출력 형식
```
# [기업명] 가격 판독 — 역DCF
생성일: YYYY-MM-DD

## 입력값
| 항목 | 값 | 출처 |
|---|---|---|

## 역산 결과 (WACC 민감도)
| WACC | 요구 성장률(10년 CAGR) |
|---|---|
| 7% | X% |
| 9% | X% |
| 11% | X% |

## 과거 실제 성장률
| 기간 | FCF CAGR | 매출 CAGR |
|---|---|---|

## 갭 분석
[해석] 요구 성장률 X% vs 과거 실제 Y% → 갭 Z%p
근거가 될 만한 사실: [사실] ... (출처)

## 확인 필요
- ...
```

## 저장
결과물은 `output/cards/[티커]_price_[YYYY-MM-DD].md`로 저장한다.

## 금지사항
- "지금 사도 된다/안 된다"라고 결론짓지 않는다. 갭과 그 갭을 메울 근거가 있는지 여부까지만 제시한다.
- 계산은 반드시 코드 실행 결과를 그대로 인용한다. 암산 결과를 쓰지 않는다.
- WACC 단일값만 쓰지 않는다 — 민감도 분석 필수.
