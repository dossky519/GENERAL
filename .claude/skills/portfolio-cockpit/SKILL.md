# 포트폴리오 콕핏 (Portfolio Cockpit)

시작하기 전에 `.claude/skills/investing-principles.md`를 반드시 먼저 읽는다.

## 입력
`data/portfolio.md`에 사용자가 수동으로 기록해둔 보유 현황(종목, 자산유형, 평가금액, 통화)을 읽는다. 이 파일이 없거나 비어 있으면 먼저 사용자에게 입력을 요청한다. 실시간 계좌 연동은 하지 않는다 — 자격증명을 다루지 않는 게 안전하다는 설계 원칙이다.

## 프로세스
1. **자산유형 분류** — 종목마다 유형을 판정한다: 개별주 / 지수 ETF / 액티브 ETF(커버드콜 등) / 원자재 ETF / 채권 / 현금 등. 유형별로 평가 기준을 다르게 적용한다.
   - 개별주: 펀더멘털·역DCF 적용 가능 (`company-decoder`, `price-decoder`와 연계 가능)
   - 지수 ETF: 개별 종목 펀더멘털 대신 지수 전체 밸류에이션(PER 등)으로 평가
   - 액티브 ETF(커버드콜/옵션인컴, 예: JEPI·DIVO·QQQI·NVDY류): 배당수익률만 보지 않는다. 분배금 중 옵션 프리미엄·자본잠식(ROC) 비중, NAV(기초가격) 장기 추이, 기초지수 대비 상승장 캡(cap) 여부를 함께 본다. 고배당률이 곧 고수익을 의미하지 않는다는 걸 명시한다.
   - 원자재 ETF(금 등): 펀더멘털 자체가 없다는 걸 명시하고, 실질금리·달러 방향 등 다른 잣대를 쓴다고 밝힌다
2. **집중도 계산** — 코드로 HHI(허핀달-허쉬만 지수)를 계산한다(종목 비중의 제곱합). 값이 높을수록 집중도가 높다는 걸 설명과 함께 제시한다.
3. **숨은 중복 노출 계산** — 보유한 지수 ETF의 구성종목 중 상위 비중 종목이, 별도로 보유 중인 개별주와 겹치는지 확인한다(웹검색으로 ETF 구성 확인). 겹치는 경우 실질 노출 비중을 합산해서 보여준다.
4. **환율 노출도** — 해외자산(원화 외 통화 표시 자산) 비중을 계산하고, 원화 환산 수익률이 환율에 얼마나 민감한지 코드로 계산한다.
5. **리스크·수익 기여도** — 종목별 비중과 최근 수익률을 근거로 포트폴리오 수익에 각 종목이 얼마나 기여했는지 계산한다.

## 출력 형식
```
# 포트폴리오 콕핏 — YYYY-MM-DD

## 자산유형별 요약
| 유형 | 비중 | 평가기준 |
|---|---|---|

## 집중도 (HHI)
HHI = X (계산 근거 코드 포함)
[해석] ...

## 숨은 중복 노출
| 개별주 | 겹치는 ETF | 실질 합산 비중 |
|---|---|---|

## 환율 노출도
해외자산 비중 X% → 환율 민감도 추정 [해석]

## 종목별 리스크·수익 기여도
| 종목 | 비중 | 최근 수익률 | 기여도 |
|---|---|---|---|

## 더 파볼 것 (신호)
- ...
```

## 저장
결과물은 `output/cards/portfolio_[YYYY-MM-DD].md`로 저장한다.

## 금지사항
- 리밸런싱 비중을 대신 정해주지 않는다. 계산 결과와 시나리오만 제시한다 (예: "A종목을 5%p 줄이면 HHI가 X→Y로 변화").
- 세금 계산도 마찬가지로 시나리오만 보여주고 결정은 사용자가 한다.
