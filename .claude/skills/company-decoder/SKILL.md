# 기업 해독기 (Company Decoder)

시작하기 전에 `.claude/skills/investing-principles.md`를 반드시 먼저 읽고, 5원칙(출처·계산·사실해석분리·매매신호금지·1차스크리너)을 그대로 따른다.

## 목적
"이 회사 뭐 하는 회사야?"라는 질문에 10분 안에 답이 되는 **한 장 요약 카드**를 만든다. 심층 분석이 아니라 빠른 이해가 목표다. (지난 몇 년간의 변화 추적은 `story-reader`, 밸류에이션은 `price-decoder` 스킬로 넘긴다.)

## 입력 모드 판단
1. **웹검색 모드** — 티커/기업명만 주어진 경우. 최신 웹검색으로 사업 개요, IR 자료, 뉴스를 근거로 카드를 작성한다. 각 항목에 검색 URL을 출처로 남긴다.
2. **정밀 모드** — 10-K/사업보고서 PDF가 업로드된 경우. 업로드 문서를 1차 출처로 쓰고, 인용마다 페이지 번호를 명시한다. 실제로 확인한 페이지만 쓴다.

두 모드가 섞여도 된다(업로드 문서 + 최신 뉴스 보완). 이 경우 항목별로 출처 종류를 구분해 표기한다.

## 프로세스
1. **돈 버는 구조 파악** — 이 회사가 무엇을 팔아서 어떻게 돈을 받는지(구독, 일회성 판매, 라이선스, 광고, 수수료 등)를 한 문단 + 텍스트 기반 흐름도로 표현한다.
2. **매출 분해** — 최근 회계연도 매출을 두 축으로 쪼갠다: (a) 사업부문별, (b) 지역별. 각각 비중(%)과 전년 대비 증감을 표로 정리한다.
3. **업종별 핵심지표 선택** — 아래 표를 기준으로 이 업종에서 진짜 중요한 지표 2~4개를 뽑아 최근 수치와 추이를 보여준다.

   | 업종 | 핵심 지표 예시 |
   |---|---|
   | 구독형 서비스(SaaS 등) | 이탈률(churn), NRR, ARPU |
   | 제조업 | 가동률, 재고회전율, 설비투자 대비 매출 |
   | 소매/유통 | 동일점포매출(SSS), 객단가, 매장당 매출 |
   | 플랫폼/광고 | MAU/DAU, 사용자당 매출(ARPU) |
   | 금융 | NIM(순이자마진), 연체율, 자기자본비율 |

   업종이 표에 없으면 그 업종의 실질적 핵심지표를 판단해서 근거와 함께 쓴다.
4. **재무 스냅샷** — 매출, 영업이익률, 순이익, FCF 최근 3~5개년 추이를 코드 실행으로 계산해 표로 정리한다. 이상치(전년 대비 ±40% 이상 급변 등)는 별도 표시하고 가능하면 원인을 원문에서 찾아 인용한다.
5. **리스크 한 줄씩** — 사업보고서에 명시된 리스크 요인 중 실질적으로 중요한 2~3개를 `[사실]`로 요약한다.

## 출력 형식 — 한 장 요약 카드
```
# [기업명] ([티커]) — 기업 해독 카드
생성일: YYYY-MM-DD | 모드: 웹검색 / 정밀(업로드 문서 기반)

## 한 줄 요약
[해석] ...

## 돈 버는 구조
[사실] ... (출처: URL 또는 p.XX)

## 매출 구성
| 구분 | 비중 | 전년 대비 |
|---|---|---|

## 업종 핵심지표
| 지표 | 최근값 | 추이 |
|---|---|---|

## 재무 스냅샷 (최근 3~5개년)
| 연도 | 매출 | 영업이익률 | FCF |
|---|---|---|---|
※ 이상치: ...

## 리스크 요인
1. [사실] ...
2. [사실] ...

## 확인 필요
- (출처를 못 찾은 항목들)
```

## 저장
결과물은 `output/cards/[티커]_[YYYY-MM-DD].md`로 저장한다.

## 금지사항
- 매수/매도 의견, 목표주가를 제시하지 않는다.
- 출처 없는 숫자를 쓰지 않는다. 모르면 "확인 필요"로 남긴다.
- 페이지 번호를 추측하지 않는다.
