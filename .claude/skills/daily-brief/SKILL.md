# 일일 브리핑 (Daily Brief)

시작하기 전에 `.claude/skills/investing-principles.md`를 반드시 먼저 읽는다.

## 입력
- `data/portfolio.md` — 보유 종목
- `data/watchlist.md` — 관심 종목/테마
- 웹검색 — 밤사이 가격 변동, 환율, 매크로 지표, 뉴스, 실적 발표 일정

## 프로세스
1. **보유 종목 밤사이 움직임** — `data/portfolio.md`의 각 종목 최근 가격 변동을 웹검색으로 확인. ±5% 이상 급변한 종목은 별도 표시.
2. **매크로** — 환율(특히 원화 관련), 주요 금리, 관심 매크로 지표의 밤사이 변화를 정리.
3. **관심 테마 뉴스** — `data/watchlist.md`의 테마/종목 관련 뉴스 중 유의미한 것만 요약(뉴스 나열이 아니라 "왜 중요한지" 한 줄).
4. **다가오는 이벤트** — 실적 발표, 배당락일, 주요 매크로 발표(FOMC 등) 등 향후 1~2주 내 일정을 정리.
5. **오늘의 액션 신호 생성** — 아래 규칙으로 신호를 판정한다.
   - 실적 발표가 7일 이내로 임박 → "`story-reader`로 [종목] 돌려보기 권장"
   - 밤사이 ±5% 이상 변동 → "`price-decoder`로 [종목] 밸류 재점검 권장"
   - 처음 보는 종목이 watchlist에 추가됨 → "`company-decoder`로 [종목] 먼저 훑어보기 권장"
   - 그 외 특이사항 없으면 "오늘은 특별한 신호 없음"이라고 정직하게 쓴다.
6. 브리핑 결과를 `output/briefs/YYYY-MM-DD.md`로 저장한다.

## 출력 형식
```
# 일일 브리핑 — YYYY-MM-DD

## 보유 종목 밤사이 움직임
| 종목 | 변동 | 비고 |
|---|---|---|

## 매크로
[사실] 환율: ... / 금리: ...

## 관심 테마 뉴스
- [사실] ... (왜 중요한지 [해석]) — 출처

## 다가오는 이벤트
| 날짜 | 종목 | 이벤트 |
|---|---|---|

## 오늘의 액션 신호
1. [종목] → story-reader 권장 (사유: 실적 D-3)
2. [종목] → price-decoder 권장 (사유: 밤사이 -6%)

(신호 없으면: "오늘은 특별한 신호 없음")
```

## 금지사항
- 매매 판단을 내리지 않는다. "더 파봐야 할 곳"만 짚는다.
- 신호가 없는데 억지로 만들지 않는다.
